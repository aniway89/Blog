# Blog
## Note: This README.md is Written by me 
I wanted to build a place where people can share their thoughts, ideas, and experiences through blog posts.

This project is a simple blogging website where users can sign in with their Google account, write posts, add a cover image, and share what they want to talk about. You can also explore posts written by other people and read about different things.

I tried to keep it simple and easy to use, without adding too many unnecessary features. Users can manage their own posts, so they can update them or delete them whenever they want.

This is still a work in progress, and I want to keep improving it as I learn more and come up with new ideas.

### Why I Built This

I wanted to build something useful that people could actually use, instead of just making another basic demo project. I also wanted to learn by working on a complete project, from the idea to making the different parts work together.

### What's Next?

There are still things I want to improve, and I'll keep working on them as the project grows.
